# Client Content Directory

Please place all client-provided documents here. Supported formats:

- PDF (.pdf)
- Word Documents (.docx, .doc)
- Text Files (.txt)
- Markdown (.md)

## Purpose

These files will be analyzed to extract:

1. **Company Profile**: Mission, Vision, Values, History.
2. **Services/Sectors**: Detailed descriptions of recruitment sectors.
3. **Tone of Voice**: The corporate language and style to be used.
4. **Key Statistics**: Global presence, placement numbers, success stories.
5. **Testimonials/Clients**: Real client feedback and partnership details.
